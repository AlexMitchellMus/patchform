### Prerequisites

#### Packaging

##### Windows:

NSIS Installation Required
To package the application for Windows using the provided build system, NSIS (Nullsoft Scriptable Install System) must be installed on your system.

You can download NSIS from the official website: https://nsis.sourceforge.io/.

Ensure that makensis is available in your system's PATH before running the build process. Without NSIS, the Windows packaging step will fail.

Installer will be built to: /installer/windows/PlugPatchInstaller.exe
